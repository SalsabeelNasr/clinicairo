# CureFit

Arabic-only marketing site for a weight-loss tele-clinic. Patients outside Egypt follow up with Egyptian specialists while using GLP-1 injections locally.

## Stack

- Next.js 16 (App Router)
- Tailwind CSS 4
- next-intl (Arabic, RTL)
- Primary brand color: `#ecd040`

## Pages

| Route | Description |
|-------|-------------|
| `/` | Landing page |
| `/doctors` | Doctor listing |
| `/doctors/[slug]` | Doctor profile with embedded videos |
| `/terms` | Terms (footer link only) |

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
